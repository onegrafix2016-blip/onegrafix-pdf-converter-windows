# Changelog

## 1.0.1 — 2026-11-03
- Fixed Inno Setup AppId and installer icon configuration.
- Added password-protected PDF support with per-file password prompts.
- Added embedded PDF image extraction into Word documents.
- Improved text-first and OCR fallback for PDF-to-Excel.
- Added PDFium to support local scanned-page rendering.
- Added isolated LibreOffice profiles for document-to-PDF conversion.
- Added automated OCR, password, image, document and UI-import tests.
- Improved Windows BAT, PowerShell and GitHub Actions build workflows.
